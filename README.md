Я самостоятельно проектировала сценарии, системные промпты, память, маршрутизацию, интеграции с API и пользовательские цепочки.

Рабочий Python-MVP игры на компьютерном зрении: камера, MediaPipe, ONNX-модель FER+, игровой сценарий, события в JSONL, аналитика результатов и отправка отчётов в Telegram. Подготовлено 58 автоматических тестов по пяти модулям.

Описание, код и демонстрация аналитики: [02_computer_vision_emotion_game](02_computer_vision_emotion_game/README.md).
