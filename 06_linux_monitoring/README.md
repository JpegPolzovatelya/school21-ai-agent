# Linux Monitoring v2.0 — School 21

## Что это за проект

Технический учебный проект по администрированию Linux и наблюдаемости серверов. Он охватывает путь от генерации тестовых данных и логов до анализа, метрик Prometheus и дашбордов Grafana.

## Что я реализовала

- модульные Bash-скрипты с проверкой аргументов и обработкой ошибок;
- генерацию файлов, каталогов и журналирование операций;
- безопасные сценарии поиска и очистки тестовых данных;
- генерацию nginx-логов в Combined Log Format;
- анализ логов через `awk` и подготовку отчёта GoAccess;
- конфигурацию Prometheus, Node Exporter и Grafana;
- Grafana dashboard JSON и provisioning-конфигурацию;
- скрипты для проверки сетевой нагрузки.

В подборку включён **31 Bash-скрипт** и конфигурационные файлы. Все shell-файлы прошли синтаксическую проверку `bash -n`, а dashboard JSON — проверку структуры через `jq`.

## Зачем этот кейс в продуктовом портфолио

Проект показывает, что я понимаю не только интерфейс продукта, но и эксплуатационный контур: логи, метрики, мониторинг, диагностику ошибок и инфраструктуру, от которой зависит стабильный пользовательский опыт.

## Инструменты

Bash, Linux, nginx logs, `awk`, GoAccess, Prometheus, Node Exporter, Grafana, JSON, YAML и Git.

## Ограничения проверки

Скрипты генерации файлов и нагрузки намеренно не запускались на рабочем компьютере: они рассчитаны на изолированную Ubuntu Server VM и могут создавать большой объём тестовых данных. В портфолио подтверждены наличие исходников и синтаксическая корректность, но не заявлен свежий end-to-end запуск всей инфраструктуры.
