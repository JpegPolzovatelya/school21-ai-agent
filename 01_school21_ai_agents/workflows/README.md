# School 21 AI Agent

Учебные n8n-workflow для создания AI-агентов и автоматизации задач.

## Проекты

- Telegram-ассистент с LLM и памятью;
- агент для подготовки публикаций из RSS-источников;
- агент для поиска и анализа вакансий;
- Telegram-бот для обучения и генерации контент-плана;
- RAG-сценарий с загрузкой документов и векторным поиском.

## Стек

`n8n`, LLM API, Telegram Bot API, RSS, HTTP API, RAG, embeddings.

## Безопасность

Из экспортов удалены идентификаторы подключений, chat ID, webhook ID и служебные данные экземпляра n8n. Для запуска нужно подключить собственные учётные данные в n8n.
